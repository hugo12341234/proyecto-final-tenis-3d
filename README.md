# Proyecto Final: Escenario Deportivo 3D Interactivo (Tenis)

Proyecto final del Laboratorio de Computación Gráfica e Interacción Humano-Computadora, Facultad de Ingeniería, UNAM (semestre 2027-1).

Escenario 3D interactivo de una cancha de tenis, hecho con OpenGL moderno (3.3) en C++. Se desarrolla aplicando lo visto en las prácticas del laboratorio: modelado jerárquico, carga de modelos, texturizado, iluminación, cámaras y animación.

**Estado:** en desarrollo.
